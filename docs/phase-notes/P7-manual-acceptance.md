# P7 实机验收记录表

状态：待执行。此表提供操作步骤，不代表任何项目通过；最终勾选仍在 [移植计划](../PORTING_PLAN.md) §5。

每次运行记录：日期、Windows build、CPU/GPU/RAM、权限级别、开发者模式、显示器分辨率/缩放、版本及提交、ZIP SHA-256、数据目录、样本数量/图片尺寸、网络条件。失败附日志和最短复现，成功附截图/录屏或文本输出路径。

## 准备

1. 使用可丢弃的插件库副本及测试游戏目录；准备有效/损坏 VPK、addonroot、重复文件、依赖与启用冲突、标签、预览图及工坊条目。记录样本来源。
2. 从完成依赖检查的 ZIP 全量解压。当前 ZIP 流程尚未通过，不以 bin 中 EXE 替代干净机器分发验收。
3. 用独立 PowerShell 进程设置绝对路径 `$env:FIREAXE_DATA_DIRECTORY = 'C:\FireAxe-P7-Test\Profile'` 后启动，先配置关闭自动更新与剪贴板检测，再进行需要网络的专门测试。不要复用真实配置或真实游戏目录。
4. 每条记录实际值、证据、结论（通过/失败/未执行）；未执行不得勾选。修改代码后重验受影响项目。
